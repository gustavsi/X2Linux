- Verified M3.9 Deliverables:
  - **Virtual-Memory Placeholders (`crates/x2l-hle-kernelx/src/{xmem,valloc_flags}.rs`, `crates/x2l-core/src/lib.rs`, `crates/x2l-pe-shims/{shim-common,kernelx}/`):**
    - `MEM_RESERVE | MEM_RESERVE_PLACEHOLDER` reserves a `< 44-bit` `PROT_NONE` placeholder span (placeholder protection such as `0x7` is ignored). `VirtualFree(..., MEM_RELEASE | MEM_PRESERVE_PLACEHOLDER)` splits a placeholder 2- or 3-way, or restores an entire live region back to a placeholder; partial preserve on a live mapping fails with `ERROR_INVALID_PARAMETER` (counted with caller RVA in `report.json`).
    - `MEM_COALESCE_PLACEHOLDERS` merges exactly-spanned adjacent placeholders; `MEM_REPLACE_PLACEHOLDER` replaces an exact placeholder with a private allocation (`XMemVirtualAlloc`, `VirtualAlloc`/`Ex`, `VirtualAlloc2`/`FromApp`) or mapped physical pages (`XMemMapPhysicalPages`/`Scatter`); `MEM_RELEASE` unmaps only the target region so split neighbors stay valid. `VirtualQuery` reports placeholders as `MEM_RESERVE` / `MEM_PRIVATE` / `PAGE_NOACCESS` with per-split bounds.
    - The IAT patcher routes `VirtualFreeEx`, `VirtualAlloc2`, and `VirtualAlloc2FromApp` (kernel32, kernelbase, and memory API sets) for arena addresses; arena `VirtualAlloc2*` calls with extended parameters return `ERROR_NOT_SUPPORTED`.
  - **DXGI Parity & Descriptor Heaps (`crates/x2l-gpu-vk/src/{dxgi,com,com_guid,features,vulkan,lib}.rs`, `tests/gpu_d3d12x_expanded.rs`):**
    - `ID3D12DeviceX::QueryInterface` (Vulkan and Null) returns refcounted `IDXGIDevice`–`IDXGIDevice4` / `IDXGIObject` sub-objects: `GetAdapter`, GPU thread priority, and frame latency. `IDXGIAdapter`–`IDXGIAdapter4` implement `GetDesc`/`1`/`2`/`3` (host Vulkan device name, vendor/device IDs, heap sizes), `QueryVideoMemoryInfo`, `CheckInterfaceSupport`, and `EnumOutputs` (`0` → `IDXGIOutput`, `1+` → `DXGI_ERROR_NOT_FOUND`). `IDXGIOutput` implements `GetDesc` (3840×2160, attached), `GetDisplayModeList`, `FindClosestMatchingMode`, and `WaitForVBlank`; a minimal `IDXGIFactory`–`IDXGIFactory6` enumerates the same adapter, and swap-chain creation returns logged `DXGI_ERROR_UNSUPPORTED`. Struct layouts carry compile-time x64 size asserts.
    - GPU-VA-backed shader-visible descriptor heaps (1,000,000 `CBV_SRV_UAV`, 2048 `SAMPLER`), dual struct-return `Get{CPU,GPU}DescriptorHandleForHeapStart`, and overlap-safe, bounds-checked `CopyDescriptors` / `CopyDescriptorsSimple` (device slots `23`/`24`). A 4,096-descriptor copy ring binds SRV/UAV near the end of a million-entry heap and is verified by compute readback.
    - Vulkan format mapping for BC1–BC7 (UNORM/SRGB), `R16G16B16A16_FLOAT`, `R11G11B10_FLOAT`, `R10G10B10A2_UNORM`, `R32_FLOAT`, `R32_UINT`, `R8_UNORM`, `R8G8_UNORM`, `B8G8R8A8_UNORM`, `R8G8B8A8_UNORM_SRGB`, `D32_FLOAT_S8X24_UINT`, and `D24_UNORM_S8_UINT` (logged fallback when unsupported); placed textures use dedicated Vulkan images with heap bounds/alignment checks.
